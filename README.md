# Pastelaria Meia Lua

Site demonstrativo, responsivo e totalmente front-end para a Pastelaria Meia Lua.

## Cloudflare Pages

- Framework preset: `None`
- Build command: deixe em branco
- Build output directory: `dist`

O site também possui uma cópia dos arquivos públicos na raiz para evitar erro 404 em projetos configurados com saída `/` ou `.`.

Não há variáveis de ambiente nem dependências para instalar.
